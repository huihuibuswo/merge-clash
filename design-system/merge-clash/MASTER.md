# Merge Clash Design System

> 页面实现先读取本文件。若 `pages/<page>.md` 存在，则页面文件只覆盖明确列出的局部规则。

## 1. 设计定位

- 产品类型：桌面网络配置与订阅管理工具。
- 使用场景：重复拉取、比较、编辑、验证和发布，用户需要快速扫描大量状态。
- 风格：高密度、安静、实用、可审计；不使用营销页构图、超大标题、装饰性渐变或玻璃拟态。
- 设计参数：Variance 3/10，Motion 3/10，Density 8/10。
- 默认主题：浅色；提供完整深色主题。
- 信息层级：状态和异常优先，装饰让位于可读性。

## 2. 核心原则

1. 每个页面只保留一个主要操作。
2. 表格用于比较，表单用于编辑，抽屉用于查看上下文，模态框用于短任务和确认。
3. 颜色不能单独表达状态，必须同时提供图标或文本。
4. 异步操作必须显示当前阶段、耗时和可恢复动作。
5. 编辑草稿与已发布版本必须始终可区分。
6. 订阅 URL、访问令牌和节点凭据默认脱敏。
7. 所有操作可用键盘完成，拖拽必须提供按钮或菜单替代方案。

## 4. 字体与数字

- UI 字体：`system-ui, "Segoe UI", "Microsoft YaHei UI", sans-serif`。
- YAML、URL、哈希、端口：`ui-monospace, "Cascadia Code", Consolas, monospace`。
- 不依赖 Google Fonts，避免离线桌面应用出现字体网络请求和闪烁。
- 字号：12 / 13 / 14 / 16 / 20 / 24px。
- 正文默认 14px，行高 1.5；紧凑表格 13px；辅助文本不得小于 12px。
- 标题字重 600，标签 500，正文 400。
- 字母间距统一为 0；数字列使用 tabular-nums。

## 5. 间距、圆角与层级

| Token | Value |
|---|---|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-6` | 24px |
| `--space-8` | 32px |

- 页面内边距：16px；宽屏可增至 24px。
- 工具栏高度：44px；顶部栏 52px；侧栏宽 216px，折叠宽 56px。
- 常规控件高度：34px；紧凑控件 30px；图标按钮点击区至少 32x32px。
- 表格表头 36px，数据行 40px；长列表超过 50 项使用虚拟滚动。
- 圆角：输入框和按钮 4px，面板 6px，模态框 8px；不使用胶囊形状承载普通文本。
- 页面区块不做漂浮卡片；只有重复模板项、模态框和明确工具面板使用边框容器。
- 阴影只用于弹窗、下拉菜单和临时浮层，常规页面使用边框分层。
- z-index：内容 0，粘性工具栏 10，下拉/浮层 100，模态框 1000，通知 1100。

## 6. 图标

- 使用 `lucide-vue-next`，统一 outline 风格和 1.75px stroke。
- 导航 18px，工具按钮 16px，空状态 32px。
- 图标按钮必须有 `aria-label` 和 tooltip；导航必须图标加文字。
- 禁止使用 emoji 作为导航、状态或操作图标。
- 建议映射：概览 `LayoutDashboard`，模板 `PanelsTopLeft`，订阅 `Link2`，分组 `Network`，预览 `FileCode2`，发布 `RadioTower`，设置 `Settings`，刷新 `RefreshCw`，测试 `Activity`，复制 `Copy`，二维码 `QrCode`。

## 7. 组件规则

### 7.1 按钮

- 每页最多一个 primary 按钮；次要操作使用 secondary/tertiary。
- 异步按钮进入 loading 并禁用重复提交。
- 删除与令牌重置使用 error 样式，并与主操作保持空间分离。
- hover/pressed 只改变颜色、边框或透明度，不移动布局。

### 7.2 表单

- 标签始终可见，不能只依赖 placeholder。
- URL、端口等复杂字段提供持久帮助文本。
- 输入错误在 blur 后显示于字段下方；提交时聚焦首个错误。
- 多个错误同时存在时，顶部显示可跳转的错误摘要。
- 只读与禁用状态必须视觉和语义不同。

### 7.3 表格和列表

- 表头可排序时显示方向并设置 `aria-sort`。
- 行悬停只做浅背景变化；选中行同时显示复选框和背景。
- 批量选择后显示稳定的批量操作栏，不让表格上下跳动。
- URL 和错误摘要截断时提供 tooltip；敏感 URL tooltip 仍保持脱敏。
- 空、加载、错误、部分成功状态必须有独立呈现。

### 7.4 状态反馈

- Success：图标 + “成功”文本。
- Warning：图标 + 原因 + 下一步。
- Error：图标 + 失败阶段 + 重试或编辑动作。
- 运行超过 300ms 显示进度；超过 1s 使用步骤进度或骨架，不用全屏阻塞 spinner。
- Toast 使用 `aria-live="polite"`，错误使用 `role="alert"`；Toast 不抢夺焦点。

## 8. 布局与响应式

- 推荐窗口：1280x800；最小支持：960x640。
- `>= 1200px`：完整侧栏，分组编辑器三栏。
- `960-1199px`：折叠侧栏，分组编辑器两栏，节点库通过抽屉打开。
- `< 960px`：不作为桌面正式工作区，显示可操作的单栏降级布局，不允许内容重叠。
- 固定栏必须为滚动内容预留空间，避免表格或按钮被遮挡。
- 避免多层嵌套滚动；三栏编辑器仅节点列表和成员列表可独立滚动。

## 9. 动效

- 状态、折叠、弹窗：150-200ms；页面切换：不超过 220ms。
- 仅使用 opacity 和 transform，不动画 width/height/top/left。
- 不引入 GSAP；Naive UI transition 和 CSS 足够。
- 尊重 `prefers-reduced-motion`，关闭非必要位移和旋转动画。
- 刷新图标可以旋转，但必须与真实任务状态绑定，任务结束立即停止。

## 10. 可访问性与键盘

- Tab 顺序与视觉顺序一致，所有功能可用键盘操作。
- 焦点环 2px，不能通过 `outline: none` 移除。
- 路由切换后把焦点移动到主内容标题。
- 模态框需要焦点锁定、Esc 关闭和明确取消按钮；有未保存修改时先确认。
- 拖拽排序同时提供上移/下移命令。
- 状态不只依赖红绿颜色，必须有图标和文本。
- 长文本优先换行；必须截断时提供安全的完整查看方式。

## 11. 禁止模式

- 营销式 Hero、定价卡片、超大标题和大面积留白。
- 装饰性渐变、发光球、玻璃拟态和持续动画。
- 卡片嵌套卡片、所有区块都卡片化。
- 一屏使用多个同等强调的主按钮。
- hover 才能发现的关键操作。
- 直接在前端展示完整订阅 URL、令牌或节点凭据。
- 仅显示“失败”而不给失败阶段和恢复动作。

## 12. 交付检查

- 浅色和深色主题分别检查文本、边框、焦点、禁用和状态对比度。
- 键盘完成添加订阅、连接测试、选择模板、编辑分组和发布流程。
- 960x640、1280x800、1440x900 下无重叠、遮挡和不可达操作。
- 50+ 节点列表滚动顺畅，筛选输入有 debounce，大对象使用 `shallowRef`。
- 所有异步操作有 loading、成功、失败和取消/重试状态。
- 所有图标来自 Lucide，图标按钮具备 tooltip 和 `aria-label`。
- 草稿与已发布版本在所有相关页面均有明确文本状态。
